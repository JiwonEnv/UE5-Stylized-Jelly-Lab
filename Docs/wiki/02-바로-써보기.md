# 🚀 2. 바로 써보기

> 원리를 몰라도 됩니다. **이미 만든 인스턴스를 복사 → 텍스처 끼우기 → 메시에 드래그** 가 전부입니다.

## 0. 언리얼 화면에서 쓰는 곳 세 군데

| 이름 | 위치 | 여기서 하는 일 |
|---|---|---|
| **콘텐츠 브라우저** | 화면 아래 (안 보이면 `Ctrl + Space`) | 파일 찾기 · 복사 · 이름 바꾸기 |
| **디테일 패널** | 화면 오른쪽 | 선택한 물체의 설정 (머티리얼 칸, 스텐실 등) |
| **인스턴스 창** | 인스턴스를 더블클릭하면 열림 | 슬라이더와 텍스처 칸 |

**용어 두 개만:**
- **머티리얼** = 레시피 원본 (노드 그래프). 직접 고칠 일은 거의 없음
- **머티리얼 인스턴스(MI)** = 같은 레시피에 **간만 다르게** 한 것. 슬라이더만 보임 ← 주로 이걸 만짐

---

## 1. 메시 가져오기

1. FBX 를 콘텐츠 브라우저의 `Art/Characters/Jelly` 폴더로 드래그
2. 메시 더블클릭 → 디테일에서 **Nanite Support 체크 해제** → Apply

> **왜?** 반투명 젤리에 Nanite 가 켜져 있으면 약 3천 삼각형짜리 거친 대체 메시로 그려져 각져 보입니다.

## 2. 텍스처 가져오기

Painter 에서 만든 4장을 `Art/Textures/Jelly` 로 드래그한 뒤, 각각 열어서:

| 텍스처 | sRGB | Compression Settings |
|---|:---:|---|
| BaseColor | ✅ 켬 | Default |
| Normal | ⬜ 끔 | **Normalmap** |
| Mask | ⬜ **끔** | **Masks** |
| Paint | ⬜ **끔** | **Masks** |

> **왜 sRGB 를 끄나?** Mask 는 색이 아니라 숫자(두께 등)입니다. sRGB 가 켜지면 숫자가 왜곡돼 두께가 틀어집니다.
> 텍스처를 아직 안 만들었다면 [Painter 텍스처 만들기](05-Painter-텍스처-만들기) 로.

## 3. 인스턴스 복사하기

1. [갤러리](01-젤리-갤러리) 에서 원하는 느낌의 인스턴스를 고름
2. 콘텐츠 브라우저에서 우클릭 → **Duplicate** → 이름 바꾸기 (예: `MI_Gummy_MyRed`)

> **왜 복사?** 프리셋마다 수십 개 값이 맞춰져 있습니다. 원본을 고치면 다른 곳에 쓰인 젤리도 같이 바뀝니다.

## 4. 텍스처 끼우고 메시에 입히기

1. 복사한 인스턴스 더블클릭 → **Textures** 그룹을 펼침
2. 칸에 내 텍스처를 드래그

   | 칸 | 넣을 것 |
   |---|---|
   | `BaseColor Tint` | 내 BaseColor |
   | `Normal` | 내 Normal (속 글리터 버전은 기본 타일을 그대로 둬도 됨) |
   | `Mask` | 내 Mask ← **가장 중요 (두께)** |
   | `Paint Mask` | 내 Paint (그림체용) |
   | `Brush Strokes` | 그대로 둠 (속 글리터 버전에만 있는 칸) |

3. 인스턴스를 뷰포트의 메시 위로 드래그

> ⚠️ `MI_Jelly_RedPainted_InnerGlitter_Restored` 는 텍스처가 머티리얼 안에 고정돼 있어 칸이 없습니다. 같은 룩에 칸을 연 **`…_TexParam`** 을 쓰세요.

## 5. (그림체일 때만) 유화 필터 연결

그림체 프리셋(`PinkPainted`, `AmberPainted`, `RedPainted`, `InnerGlitter`)은 화면 필터가 있어야 붓으로 칠한 느낌이 납니다.

![유화 필터 끔 / 켬](images/filter.jpg)

1. 젤리 메시 선택 → 디테일 검색창에 `custom depth`
2. **Render CustomDepth Pass** ✅, **CustomDepth Stencil Value** = `1`
3. 레벨에 Post Process Volume 이 있고 `M_PP_JellyPaintFilter` 가 들어 있는지 확인 (`L_JellyLookDev` 에는 이미 있음)

> **왜 스텐실?** 필터는 화면 전체에 걸리는 효과라, "스텐실 1" 로 표시한 물체에만 걸리게 해야 배경이 뭉개지지 않습니다.
> 프로젝트 설정 `Custom Depth-Stencil Pass = Enabled with Stencil` 은 이미 켜져 있습니다.

## 6. 내 메시 크기에 맞추기

테스트 곰은 높이 44cm 기준입니다. 메시 크기가 다르면 이것만 맞추세요.

| 슬라이더 | 맞추는 법 |
|---|---|
| `Object Height` | 내 메시 높이(cm) — 위·아래 색 그라데이션 기준 |
| `Brush Scale` | 메시 높이 정도 — 붓 자국 크기 |
| `Star Size` | 메시가 크면 키움 |
