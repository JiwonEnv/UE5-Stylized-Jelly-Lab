# 🗓 8. 변경 이력

젤리 머티리얼이 처음부터 지금까지 어떻게 바뀌었는지입니다. 각 단계의 모습은 [갤러리](01-젤리-갤러리) 의 ①~⑧ 에 대응합니다.

![발전 순서](images/banner.jpg)

### v0. 초기 상태 · 갤러리 ①
- 구 메시, 단색 + Fresnel 가장자리 변화
- Painter 텍스처 거의 단색, 두께 정보 없음 → 플라스틱처럼 보임

### v1. 재료 준비
- Substance Painter 9.0 → 12.2 (레이어 스크립트 API)
- 테스트 메시를 구 → **앉은 곰**으로 (얇은 귀·발, 두꺼운 배)
- 두께 맵: Painter 베이크가 비어 메시 형태(SDF)에서 직접 계산
- Painter 레이어: 색 얼룩(라벤더·살구), 홈 농도, 말랑한 굴곡, 흘러내림, 잔물결, 손자국, 기포
- 출력: BaseColor(흰색 틴트) / Normal / Mask(R 두께 · B 기포 · A 얼룩)

### v2. 첫 젤리 머티리얼 `M_Jelly_Gummy` · 갤러리 ②
- 두께 기반 흡수색 (얇으면 밝게, 두꺼우면 진하게)
- 두께 기반 투명도, 내부 발광, 굴절
- 색 프리셋 인스턴스 7종

### v3. 하이라이트 · 방향 수정
- 곰 회전 수정 (누움 · 뒤돌아 있음)
- 노멀 강도 · 얼룩 거칠기 · 스펙큘러 낮춤, 내부 발광 올림
- 가짜 스튜디오 하이라이트 3개 (반사 방향 기반)

### v4. Thin Translucent 전환 · 갤러리 ③
- 셰이딩 모델 **Thin Translucent** → 뒤 배경이 젤리 색으로 물듦 (창백함 해결)
- Nanite 끔 (각진 실루엣)
- Painter 빈 Normal 메시 맵 제거 후 재출력 (모래 같은 표면)
- 룩데브 바닥 교체

### v5. 다색 빛 + 그림체 1차 · 갤러리 ④ ⑤
- 높이 그라데이션 3색, 좌우 2색 림, 무지개빛
- 페인트 하이라이트(또렷한 경계 + 노이즈 일그러짐), 계단 음영, 외곽 톤, 반짝이 점
- 프리셋 `PinkIridescent`, `AmberPainted`
- 수정: 재빌드 시 Thin Translucent 출력 노드 중복 → 컴파일 실패

### v6. 그림체 2차
- Painter 채널: 붓 결(User4), 물감 덩어리(User5) → `Paint` 텍스처
- 셀 음영 3톤, 경계를 붓 결로 흔듦
- 수정: 바닥 머티리얼 미적용(액터 이름 불일치), Nanite 해제 후 메시 미재빌드(3,084 → 92,184 삼각형)

### v7. 붓질 + 유화 필터 · 갤러리 ⑥
- 붓 자국 텍스처(자국 ID / 하이라이트 대시 / 붓 결)를 Triplanar 로
- 자국별 색 흔들림, 붓 결, 흰 대시 하이라이트
- 포스트 프로세스 `M_PP_JellyPaintFilter`: Kuwahara 유화 필터, 커스텀 스텐실 1 에만
- 프리셋 `PinkPainted`, `RedPainted`
- 수정: NaN 초록 얼룩(Saturate), 필터 미적용(`r.CustomDepth=3` + 반투명 Custom Depth 쓰기), 필터 반경 6 → 4

### v8. RedPainted 통합 + 별 반짝이 · 갤러리 ⑦
- `RedPainted` 에 그라데이션 · 금색/파랑 림 · 무지개빛
- 별 반짝이: 반사 방향 방식(곡면에서 1~3px) → **별 스프라이트 텍스처** 부착 방식
- 얇은 흰 테두리(Edge Line), 유화 필터에서 밝은 부분 제외
- 수정: 빨강이 회색빛으로 바램 → 투과 0.45 · 불투명도 0.85 복구
