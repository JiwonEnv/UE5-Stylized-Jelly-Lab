# 🧪 4. 어떻게 만들어졌나

> 이 페이지는 **궁금할 때만** 읽어도 됩니다. 사용하는 데는 필요 없습니다.

## 머티리얼이란?

**화면의 점(픽셀) 하나하나를 무슨 색으로 칠할지 정하는 레시피**입니다.
코드로 쓰면 "셰이더", 상자와 선으로 그리면 "머티리얼 그래프"(유니티의 Shader Graph 와 같은 개념)입니다.

```
[재료 상자들] ──선(숫자)──▶ ┌───────────────┐
                            │ 결과 노드      │
                            │  Base Color   │ 기본 색
                            │  Opacity      │ 불투명도 (0 투명 · 1 불투명)
                            │  Emissive     │ 스스로 빛나는 색
                            │  Normal       │ 표면 굴곡
                            └───────────────┘
```

- 오른쪽 큰 상자의 **빈칸**을 왼쪽 상자들이 계산해 채웁니다.
- 선 위로 흐르는 건 전부 **숫자**입니다. 색 = 숫자 3개(R·G·B, 각 0~1), 텍스처 = 숫자가 그려진 그림.

---

## 젤리는 4층으로 쌓인다

![4층](images/layers.jpg)

| 층 | 하는 일 | 핵심 노드 |
|---|---|---|
| ① 색 | `Jelly Color` 를 Base Color 에 연결 | Vector Parameter |
| ② 두께 | Painter 의 **두께 그림(Mask.R)** 을 읽어, 두꺼울수록 `Deep Color` 쪽으로 섞음 | Texture Sample → Power → Lerp |
| ③ 투명 | 얇으면 Opacity 낮게, 두꺼우면 높게. **Thin Translucent** 로 뒤 배경을 젤리 색으로 물들임 | Lerp → Opacity, Thin Translucent 출력 |
| ④ 반짝임 | "이 방향 빛이 반사되는 곳"을 계산해 흰색을 Emissive 에 더함 + 얇은 곳이 속에서 빛남 | Reflection Vector → Dot → Power |

**림 라이트, 그라데이션, 붓질, 별** 같은 나머지 효과는 전부 같은 방식으로 위에 덧칠한 것입니다:

> **효과를 넣을 자리(0~1 마스크)를 계산 → 원하는 색을 곱하고 → 결과에 더하기**

---

## 441개 노드는 사실 5가지의 반복

| 노드 | 하는 일 | 비유 |
|---|---|---|
| **Texture Sample** | 그림에서 숫자 읽기 | 재료 꺼내기 |
| **Multiply** | 세기 조절 (0 = 끔, 2 = 두 배) | 볼륨 다이얼 |
| **Add** | 효과를 위에 얹기 | 덧칠 |
| **Lerp** | A 와 B 를 마스크 비율로 섞기 | 두 물감 섞기 |
| **Power / SmoothStep** | 경계를 부드럽게 · 또렷하게 | 붓 끝 뭉툭 / 날카롭게 |

인스턴스의 슬라이더 하나하나는 이 노드들 중 어딘가의 **숫자 하나**입니다. 예: `Density` = ②층의 Power 에 들어가는 숫자.

## 효과별로 조금 더

| 효과 | 원리 (한 줄) |
|---|---|
| 두께 흡수색 | `Jelly Color ^ (두께 × Density)` — 두꺼울수록 색이 진해짐 (빛이 젤리를 오래 통과할수록 색을 먹는 원리) |
| 투과 | Thin Translucent 의 Transmittance 에 흡수색을 넣으면, 뒤에 보이는 것이 그 색으로 곱해짐 |
| 하이라이트 | 반사 방향과 가짜 조명 방향 3개의 **내적** → 거듭제곱으로 좁힘 |
| 림 라이트 | Fresnel(가장자리일수록 1) × 좌우 방향 마스크 → 한쪽 노랑, 반대쪽 시안 |
| 무지개빛 | `0.5 + 0.5·cos(Fresnel + (0, .33, .67))` — 각도에 따라 R·G·B 가 엇갈려 변함 |
| 그라데이션 | 오브젝트 기준 높이(0~1)로 아래·중간·위 색을 섞고, 두께로 몸통 안쪽만 |
| 계단 음영 | `Floor(값 × 단계 + 0.5) / 단계` (유니티 Posterize 노드) |
| 셀 톤 | 빛 방향과 표면 방향의 내적을 두 번 SmoothStep → 그림자/중간/밝은 면 |
| 붓 자국 | 붓 자국 텍스처를 3방향(Triplanar)에서 투영, 자국 ID 로 톤 경계를 흔듦 |
| 유화 필터 | 화면 후처리. 주변 4구역 중 **색 변화가 가장 적은 구역의 평균**으로 칠함 (Kuwahara, HLSL Custom 노드) |
| 별 반짝이 | 별 그림 텍스처를 표면에 붙이고, 하이라이트 쪽에서만 보이게 |
| 속 글리터 | 별을 표면이 아니라 `Star Depth` 만큼 **안쪽**에 있는 것처럼 보이게 (머티리얼 함수로 분리) |

## Painter 는 무엇을 하나?

레시피(언리얼)가 읽을 **재료 그림**을 만드는 곳입니다.

| 그림 | 채널 | 언리얼에서 쓰는 곳 |
|---|---|---|
| BaseColor | RGB | 은은한 색 얼룩 (거의 흰색, 젤리 색에 곱해짐) |
| Normal | RGB | 잔잔한 굴곡 |
| Mask | **R 두께** · B 기포 · A 손자국 얼룩 | ②층 · 기포 반짝임 · 거칠기 |
| Paint | R 붓 결 · G 물감 덩어리 | 그림체 톤 경계 |
