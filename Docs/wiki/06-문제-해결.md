# 🩹 6. 문제 해결

## 화면이 이렇게 보이면

| 증상 | 원인 | 해결 |
|---|---|---|
| 젤리가 **회색 체크무늬** | 머티리얼 컴파일 중이거나 실패 | 잠시 기다림. 계속되면 Window → Output Log 에서 머티리얼 에러 확인 |
| 젤리가 **회색 단색** (`WorldGridMaterial`) | 인스턴스가 지워졌거나 경로가 바뀜 | 디테일 패널의 머티리얼 칸에 인스턴스를 다시 넣기 |
| **창백하고 뿌옇다** | 일반 Translucent 를 쓰거나 투과가 약함 | 마스터는 Thin Translucent 사용. `Transmission Brightness` 0.45 이상 |
| **회색빛 분홍으로 칙칙** | 투과는 낮고 불투명도는 높음 | `Transmission Brightness` 0.45 / `Opacity Thick` 0.85 근처로 |
| **각져 보인다** | 반투명 + Nanite → 거친 대체 메시 | 메시의 Nanite 끄기 (메시 자체 폴리곤이 적으면 그대로 각짐) |
| **표면이 모래처럼 거칠다** | 노멀이 너무 셈 / Painter 빈 Normal 베이크가 섞임 | `Normal Strength` 내리기, Painter 의 빈 Normal 메시 맵 슬롯 비우고 재출력 |
| **어디나 같은 진하기** | Mask R(두께)이 비었거나 sRGB 켜짐 | Painter Thickness 베이크 확인, Mask 텍스처 sRGB 끄기 |
| **흰 점투성이** | User0(기포) 채널이 전부 1 | Painter 1 번 레이어에서 User0 = 0 |
| **얼룩이 엉뚱한 곳에** | 다른 메시용 텍스처를 씀 | 내 메시로 Painter 텍스처 새로 만들기 |
| **초록 빛 얼룩이 번짐** | 계산값이 범위를 벗어나 NaN → 블룸으로 번짐 | (마스터에서 해결됨) 직접 수정했다면 계단 음영 결과에 Saturate |
| **그림체 필터가 안 걸림** | 커스텀 스텐실 미설정 | 메시 `Render CustomDepth Pass` ✅ + `Stencil Value` 1, 프로젝트 `Custom Depth-Stencil Pass = Enabled with Stencil` |
| **필터가 눈·코까지 뭉갬** | 필터 반경이 큼 | `M_PP_JellyPaintFilter` 의 `Brush Radius` 4 |
| **별 반짝이가 안 보임** | Glint 가 0 이거나 Zone 이 너무 높음 | `Star Glint` 2~3, `Star Zone` 0.3 |
| **테두리 선이 너무 얇다** | 실루엣 끝 1~2px 에만 걸림 | `Edge Line` 올리기 (마스터는 안쪽 띠로 조정됨) |
| 인스턴스에 **Textures 칸이 없다** | 텍스처가 머티리얼 안에 고정된 버전 | `…_InnerGlitter_TexParam` 처럼 칸이 열린 버전 사용 |
| 슬라이더를 바꿨는데 **화면 그대로** | 셰이더 컴파일 중 / 다른 슬롯에 다른 머티리얼 | 잠시 대기, 메시의 모든 머티리얼 슬롯 확인 |

## 저장이 안 될 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 레벨·에셋 저장 실패 | Git LFS **lockable** 설정으로 `.umap`/`.uasset` 이 읽기 전용 | 파일 속성에서 읽기 전용 해제 (혼자 쓰는 저장소) 또는 `git lfs lock <파일>` |

## Painter 에서

| 증상 | 해결 |
|---|---|
| Thickness 베이크가 비어 있음 | Use Low Poly as High Poly 체크, Max Distance 0.3, 그래도 비면 두께 맵을 외부에서 만들어 리소스로 가져오기 |
| Curvature 를 마스크에 넣었더니 전체가 회색 | Levels → Invert, 입력 0.5~0.67 ([Painter 4단계 ※2](05-Painter-텍스처-만들기#4-레이어-쌓기-아래--위)) |
| 새 User 채널이 전부 흰색으로 내보내짐 | 바탕 레이어에서 그 채널 값을 0 으로 |

## 값이 망가졌을 때

인스턴스 창에서 슬라이더 오른쪽 **↺** = 부모 기본값으로 되돌리기.
어떤 슬라이더가 원인인지 모르겠으면 **하나씩 0 으로 내려 보면서** 원인을 찾습니다.
