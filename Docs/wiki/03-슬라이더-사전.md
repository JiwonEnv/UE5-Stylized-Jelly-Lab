# 🎚 3. 슬라이더 사전

머티리얼 인스턴스를 열면 보이는 슬라이더들입니다. 각 슬라이더를 **낮음 / 기본 / 높음** 으로 바꿔 같은 곰을 찍었습니다.
슬라이더는 그룹(제목줄)으로 묶여 있으니, 인스턴스 창에서 그룹을 펼쳐 찾으세요.
일부 효과(투과·무지개빛·외곽 톤·별 등)는 원래 은은해서, 비교 이미지는 **추천 범위보다 큰 값까지** 찍어 차이를 보이게 했습니다. 실제로는 각 항목의 추천값을 쓰세요.

## 🔎 빠른 찾기

| 하고 싶은 것 | 슬라이더 |
|---|---|
| 색 바꾸기 | `Jelly Color` + `Deep Color` (Deep 은 Jelly 를 어둡고 진하게) |
| 더 진하게 / 연하게 | [Density](#density) |
| 더 투명하게 | [Opacity Thick](#opacity-thick) · `Opacity Thin` |
| 뒤가 더 비치게 | [Transmission Brightness](#transmission-brightness) |
| 속에서 빛나게 | [Inner Glow](#inner-glow) |
| 반짝임 세기 | [Highlight Intensity](#highlight-intensity) |
| 표면을 매끈하게 | [Normal Strength](#normal-strength) |
| 위아래 다른 색 | [Gradient Amount](#gradient-amount) |
| 가장자리에 색 빛 | [Rim Light A](#rim-light-a) |
| 무지개빛 | [Iridescence](#iridescence) |
| 그림체로 | [Paint Style](#paint-style) · [Cel Amount](#cel-amount) · [Brush Amount](#brush-amount) |
| 외곽선 | [Outline Amount](#outline-amount) · [Edge Line](#edge-line) |
| 별 반짝이 | [Star Glint](#star-glint) |

## 💧 Jelly — 기본 젤리

### Density
![](images/slider_density.jpg)

**색의 진하기.** 높을수록 두꺼운 곳이 더 어둡고 진해집니다.
- 추천: **1.0 ~ 2.0**
- 주의: 4 이상이면 거의 검붉게 됩니다.

### Opacity Thick
![](images/slider_opacity_thick.jpg)

**두꺼운 곳의 불투명도.** 낮을수록 배·머리까지 비쳐 보입니다. 얇은 곳은 `Opacity Thin` 으로 따로 조절합니다.
- 추천: Thick **0.5 ~ 0.9**, Thin **0.1 ~ 0.4**
- 주의: 1 을 넘는 값은 의미가 없습니다 (0~1 범위).

### Transmission Brightness
![](images/slider_transmission_brightness.jpg)

**뒤 배경이 젤리 색으로 비치는 밝기.** 젤리다운 맑은 느낌의 핵심.
- 추천: **0.45 ~ 1.0**
- 주의: 0.4 아래 + 불투명도 높음 → 회색빛으로 칙칙해집니다.

### Inner Glow
![](images/slider_inner_glow.jpg)

**속에서 은은히 빛나는 느낌.** 특히 얇은 곳(귀·손발)이 밝아집니다. 색은 `Inner Glow Color`.
- 추천: **0.6 ~ 1.5**

### Highlight Intensity
![](images/slider_highlight_intensity.jpg)

**스튜디오 조명 같은 흰 반사의 세기.** 크기·또렷함은 `Highlight Sharpness`.
- 추천: **2 ~ 3.5**

### Normal Strength
![](images/slider_normal_strength.jpg)

**표면 굴곡(잔물결)의 세기.** 높으면 손으로 빚은 듯 울퉁불퉁, 낮으면 매끈.
- 추천: 사실적 **0.1 ~ 0.3**, 그림체 **0.05 ~ 0.1**
- 주의: 높으면 표면이 모래처럼 거칠어 보입니다.

## 🌈 Color Gradient · Rim / Iridescence — 여러 색 빛

### Gradient Amount
![](images/slider_gradient_amount.jpg)

**위·중간·아래 색 그라데이션의 세기.** 색은 `Gradient Mid Color`, `Gradient Bottom Color`, 위는 `Jelly Color`.
- 함께 보는 값: `Gradient Core Only` = 1 이면 두꺼운 몸통 안쪽만 색이 변하고 팔다리·가장자리는 원래 색 유지 · `Object Height` = 메시 높이(cm)
- 추천: 주색을 살리려면 **0.3 ~ 0.5**
- 주의: `Gradient Top Width` 는 0 이나 음수 금지 (그라데이션이 뒤집힘)

### Rim Light A
![](images/slider_rim_light_a.jpg)

**한쪽 가장자리에 비치는 색 빛.** 반대쪽은 `Rim Light B`. 색은 `Rim Color A/B`, 폭은 `Rim Power`.
- 추천: A **2 ~ 4**, B **0.7 ~ 1.5**, Power **2.5 ~ 3**
- 주의: Power 가 2 아래면 빛이 몸통까지 번져 탁해집니다.

### Iridescence
![](images/slider_iridescence.jpg)

**보는 각도에 따라 바뀌는 무지개빛** (비눗방울 같은 박막).
- 추천: **0.1 ~ 0.3**
- 주의: 그림체 위에서 세면 지저분해집니다.

## 🖌 Painterly · Brush Strokes — 그림체

> `Paint Style`, `Edge Line` 은 유화 필터를 **켠** 상태, 나머지는 효과가 잘 보이도록 필터를 **끈** 상태로 찍었습니다. 일부는 차이가 잘 보이게 추천 범위보다 큰 값까지 찍었습니다.
> 필터 연결은 [바로 써보기 5단계](02-바로-써보기#5-그림체일-때만-유화-필터-연결).

### Paint Style
![](images/slider_paint_style.jpg)

**그림체 스위치.** 하이라이트가 또렷한 붓 터치 모양이 되고, 음영이 계단처럼 끊깁니다(`Paint Bands` = 단계 수).
- 추천: 그림체면 **1**, 사실적이면 **0** (중간값은 섞임)

### Cel Amount
![](images/slider_cel_amount.jpg)

**셀 셰이딩 3톤** (그림자 / 중간 / 밝은 면). 톤 색은 `Shadow Tone`, `Light Tone`.
- 추천: **1**

### Brush Amount
![](images/slider_brush_amount.jpg)

**붓 자국 텍스처의 영향.** 명암이 붓 자국 모양 조각으로 끊기고, 자국마다 색이 살짝 흔들립니다.
- 함께 보는 값: `Brush Patch Breakup`(끊김 정도) · `Brush Hue A/B`(라벤더·살구 흔들림) · `Brush Scale`(붓 크기)
- 추천: **1**

### Outline Amount

> 이 곰 모델에서는 차이가 거의 보이지 않아 비교 이미지를 생략했습니다. 실루엣이 크고 매끈한 메시에서 더 잘 드러납니다.

**가장자리를 진하게 칠하는 외곽 톤.** 색은 `Outline Color` (보통 젤리색보다 어둡고 진하게).
- 추천: **0.3 ~ 1**

### Edge Line
![](images/slider_edge_line.jpg)

**실루엣 안쪽의 얇은 유리 테두리 선.** 색은 `Edge Line Color`.
- 추천: **0.3 ~ 0.8**

### Star Glint
![](images/slider_star_glint.jpg)

**별 반짝이 밝기.** `Star Points` 0 = 사각 점 · 4 = 십자 별 · 6 = 6각 별, `Star Size` = 크기, `Star Zone` = 하이라이트에서 얼마나 멀리 퍼질지.
- 추천: Glint **2 ~ 3**, Zone **0.3**
- 주의: 수십 이상은 화면이 하얗게 번쩍입니다.

---

## 🧯 값이 이상하게 들어갔을 때

인스턴스 창에서 슬라이더 오른쪽의 **↺ (되돌리기)** 를 누르면 부모 머티리얼의 기본값으로 돌아갑니다.
