# 하이브리드 젤리 설계

이 문서는 구현 계획이며 아직 게임 로직은 생성하지 않았습니다.

## 구성
- `BP_JellyCharacter`: 입력, 이동, 점프, 착지 및 충돌 신호 수집
- `BPC_JellyDeformation`: 충격 방향·강도에서 변형 목표를 계산하고 스프링 복원 상태 관리
- `DA_JellySpringProfile`: 강성, 감쇠, 최대 변형, 충격 배율 설정
- `M_JellyMaster`, `MI_JellyBlue`: WPO와 표면 표현; 캐릭터별 Dynamic Material Instance로 매개변수 전달
- 캡슐은 이동·충돌 담당, 하위 시각 메시 또는 본만 전체 실루엣 변형

## 신호 흐름
이동 속도 → 약한 WPO 흔들림. 점프 준비 → 압축, 상승 → 늘어남. 착지·벽 충돌 → 충돌 법선과 상대 접근 속도에 따른 변형 → 감쇠 스프링으로 기준 형태 복원.

착지는 OnLanded 등으로, 벽은 이동 방식에 맞는 Hit 이벤트로 검증합니다. 착지 이벤트 시 이미 수직 속도가 바뀔 수 있으므로 충돌 직전 속도를 보관합니다. 캐릭터의 운동학적 충돌에서는 NormalImpulse가 0일 수 있으므로 충격량만 의존하지 않습니다. 반복 이벤트는 쿨다운이나 임계값으로 제한합니다.

## 안정성과 한계
스프링은 Delta Seconds를 반영하고 큰 프레임 간격에서는 작은 시간 단계 또는 안정적인 보간을 사용합니다. 변형 배율의 최솟값·최댓값과 충격 상한을 두고 리셋 시 위치·속도를 함께 초기화합니다. 전체 메시 스케일과 WPO의 진폭을 별도 관리해 과도한 이중 변형을 피합니다.

WPO와 메시/본 변형은 충돌체를 자동으로 바꾸지 않습니다. 틈 통과와 부피에 따른 판정은 후속 기능입니다. WPO 경계와 그림자, 반투명 정렬·오버드로는 실제 테스트 맵과 대상 기기에서 확인합니다. 처음부터 완전한 소프트바디 시뮬레이션을 전제하지 않습니다.

## 검증 단계
1. 머티리얼: 대기·이동 시 WPO 및 색상·광택 확인
2. 캐릭터: 이동·점프·착지와 캡슐 안정성 확인
3. 변형: 낮은/높은 낙하, 벽 충돌, 연속 충돌에서 복원 확인
4. 프레임률 30/60/120 및 일시적인 큰 프레임 간격에서 발산·지속 진동 확인
5. PIE에서 안정성을 확인한 뒤 목표 플랫폼 패키징과 성능 측정

실험 맵은 `Maps/Tests`, 미검증 에셋은 `Experiments/WPO`와 `Experiments/Spring`에 보관합니다. 검증된 컴포넌트와 프로필만 정식 경로로 옮깁니다.
