# 젤리 게임 트레일러 스토리보드

## 트레일러 방향

- 형식: 게임플레이 중심 리빌 트레일러
- 권장 길이: 75초
- 핵심 메시지: 평범한 잡동사니처럼 숨고 흔적을 읽어 추적하며 붙잡힌 동료를 구할지 버리고 탈출할지 선택하는 4대1 비대칭 게임
- 감정 곡선: 귀여움과 호기심 → 의심 → 발각 → 혼란 → 구조 딜레마 → 최종 질주
- 화면 원칙: 젤리 시점과 사람 술래 시점을 교차해 같은 공간이 서로 다른 정보로 보이게 한다.
- 공개 정보 원칙: 시스템을 자막으로 길게 설명하지 않고 행동과 결과의 인과관계로 보여준다.

## 한 줄 콘셉트

사람이 방을 치울수록 숨을 곳은 사라지고, 네 젤리는 서로를 구하거나 버리며 단 하나의 탈출구를 향해 달린다.

## 내레이션 대안

내레이션 없이 환경음과 자막만으로도 성립하도록 설계한다. 내레이션을 쓸 경우 한 문장씩 짧게 사용한다.

1. `떨어진 순간, 방 전체가 사냥터가 되었다.`
2. `평범한 먼지가 되어 숨고.`
3. `남겨진 흔적으로 서로를 찾는다.`
4. `붙잡힌 친구를 구할지.`
5. `혼자 빠져나갈지.`
6. `방이 깨끗해지기 전에 선택하라.`

## 반드시 보여줄 게임 고유 장면

1. 실제 잡동사니와 변장 젤리가 한 화면에 섞여 술래가 판단하는 장면
2. 잘못 확인한 술래가 청소 동작에 묶이고 젤리가 그 틈을 이용하는 장면
3. 흔적과 환경 변화로 술래가 위치를 추론하는 장면
4. 접시 감옥에서 목숨 타이머가 연속 소모되는 장면
5. 구출과 탈출 진행 사이에서 동료가 갈라지는 장면
6. 청소 전후의 같은 구도를 비교해 은신처가 사라지는 장면
7. 착지 압축, 이동 지연, 급정지 흔들림이 읽히는 젤리 클로즈업

## 촬영과 구현 우선순위

### A 우선 제작 컷

- 방 풀샷에서 간식 통으로 이어지는 달리 줌과 청소 후 동일 구도
- 간식 통 내부, 봉지 인트로, 손이 집어 드는 3개 연결 숏
- 바스트 로우 앵글, 절취선 클로즈업, 봉지 파열의 연속 동작
- 네 젤리가 테이블에서 뛰어내리고 바닥에 압축 착지하는 로우 앵글
- 젤리 표면과 착지 변형 매크로 숏
- 먼지 변장 전후 비교
- 진짜 먼지와 변장 젤리의 술래 시점 비교
- 끈적한 흔적 추적
- 방 청소 전후 동일 구도
- 접시 감옥과 연속 타이머 UI
- 좁은 틈 압축 통과와 최종 탈출

### B 대체 가능한 연출 컷

- 과자 봉지 협동은 시스템 구현 전 사전 연출 애니메이션으로 대체 가능
- 질량 전달은 트레일러 정보량이 많아 메인 75초에서는 제외하고 게임플레이 상세 영상에서 설명
- 휴지와 물방울 변장은 초기 공개에서 모두 보여주지 말고 마지막 로고 직전 2-3프레임 티저로만 삽입 가능
- 네트워크 동기화와 성능 요소는 소비자용 트레일러가 아니라 개발 영상에서 다룬다.

## 편집 가이드

- 초반 18초의 7개 컷은 하나의 연속 동작처럼 연결한다. 손이나 봉지가 렌즈를 가리는 순간을 매치 컷 지점으로 활용한다.
- 1번과 17번은 같은 카메라 위치와 렌즈를 사용해 어질러진 방이 청소되며 은신처가 사라졌다는 변화를 비교한다.
- 5번의 찢김 직전에는 2-3프레임 정지감을 주고 6번의 파열에서 움직임과 음악을 동시에 폭발시킨다.
- 22초 이후는 1-2초 단위 몽타주로 게임의 선택지를 압축한다.
- 39초 포획에서 템포를 낮춰 구출 딜레마가 단순 액션에 묻히지 않게 한다.
- 57초부터 초반과 같은 방 구도를 반복해 청소가 라운드의 소프트 타이머임을 설명 없이 전달한다.
- UI는 목숨 3개, 연속 타이머, 탈출 진행도만 노출한다. 질량 수치와 세부 능력 아이콘은 첫 트레일러에서 숨긴다.
- 젤리의 귀여운 탄성음과 사람의 현실적인 생활 소음을 대비시켜 작은 존재의 위기감을 만든다.

## 공개 전 확인 항목

- 실제 플레이에서 제공하지 않는 카메라나 기능은 시네마틱임을 구분한다.
- 사람 술래와 젤리 양측의 실제 플레이 화면을 최소 한 장면씩 포함한다.
- 최종 빌드에 없는 휴지, 물방울, 질량 전달은 확정 전 핵심 약속처럼 강조하지 않는다.
- 캐릭터 외형만 강조하지 말고 변장 판단, 흔적 추론, 구출 선택이라는 세 가지 고유 플레이가 모두 읽히는지 무음 상태에서도 확인한다.
